# ☁️ Azure Fundamentals (AZ-900) Quick Cheat Sheet

A concise revision guide for core Azure cloud concepts and services.

## 🎯 Core Cloud Concepts
- **IaaS (Infrastructure as a Service):** You manage OS and apps (e.g., Azure VMs).
- **PaaS (Platform as a Service):** You manage apps; Azure manages OS (e.g., Azure App Service).
- **SaaS (Software as a Service):** Fully managed apps (e.g., Microsoft 365).

## 🛡️ Core Azure Services
- **Azure Virtual Machines:** On-demand computing power.
- **Azure Blob Storage:** Massively scalable object storage for unstructured data.
- **Azure SQL Database:** Managed relational database service.
