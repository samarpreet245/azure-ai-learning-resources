# 🤖 Azure AI Fundamentals (AI-900) Quick Cheat Sheet

A concise revision guide for core Artificial Intelligence concepts and Azure AI Services.

## 🧠 Core AI Concepts
- **Machine Learning (ML):** Building predictive models based on patterns in data.
- **Computer Vision:** Processing and analyzing visual information (images/videos).
- **Natural Language Processing (NLP):** Understanding, processing, and generating human language.
- **Generative AI:** Creating new original content (text, code, images) using foundational models.

## ⚡ Core Azure AI Services
- **Azure OpenAI Service:** Secure access to enterprise GPT models and DALL-E.
- **Azure AI Vision:** Object detection, facial analysis, and OCR text extraction.
- **Azure AI Search:** Enterprise search engine with vector and hybrid search capabilities.
